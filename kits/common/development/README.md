# Common development tools

| file | what |
|---|---|
| `LIBR.SAV` | The librarian, built from DEC's V5.4 sources.  No kit of the machine had one, so no library could be rebuilt |
| `ODT.OBJ` | The octal debugger, to be linked into the program it debugs |

Each kit's own assembler and linker are in its `development/`; `SYSMAC.SML` and the Pascal kit's `SYSLIB.OBJ` are in `../../../software/development/`.
