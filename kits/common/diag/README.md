# Diagnostics and timing meters

The factory exerciser `183107.SAV` (drops into ODT BY DESIGN: `D` a mode into 001076, `P` to proceed), the keyboard scan-code viewer, and the `C*` instruction-timing suite — each meter counts CPU cycles per addressing mode.  The meters need the missing EIS/FIS instructions: `R GETEML` (or `SET EM ON` with `EM.SYS`) first, then `R CMOV`, `D 1002=44760`, `ST`.
