# Handlers: Mihin's OS-16SJ

The kit's own handlers - `DZ`, `DV`, `TT`, `VM`, `LD` - all built with its sysgen, plus `HD.SYS`, the emulator's paravirtual disk, which is ours and not a recovered file.  Which of them loads under which monitor is in [`../../HANDLERS.md`](../../HANDLERS.md).  `ms0111/` holds the handlers of the work diskette 056, filed with this kit because they carry its sysgen word.

## SL as НПФ «Сенсор» adapted it

`SL V8.00`, Сторожевых's single-line editor with a banner of its own:

> «АДАПТАЦИЯ ДЛЯ УБПК НПФ "СЕНСОР"»

The copy here is amk disk3's, the one whose ten hotkey assignments were already blank; disk1's and disk2's had them filled in.  Which is why a composed disk does not announce a stranger's macros at every boot.

**УБПК is this machine.**  The Электроника МС 0515 was developed in Voronezh in 1990 and made at the «Процессор» plant; `Электроника УПБК-16` was its name while it was being developed, and a plant engineer on the zx-pk.ru forum says plainly «УБПК это и есть МС 0515».  The same thread notes what went with which name: «на МС 0515, операционка ОСА-1, на УБПК ОС-16 и ПРОС (Д)» — and OS-16 is the monitor of this kit.

**Who «Сенсор» were** is not settled here.  What the files themselves say:

* `../../../software/format/FDZ.SAV` — «ПРОГРАММА ФОРМАТИРОВАНИЯ ДИСКЕТ ДЛЯ УПБК-16», «(C) МИХИН-СОФТ & СПФ "СЕНСОР"», «(C) МИХИН-СОФТ <1990>», and the line «...РАЗРАБОТАННОЙ МИХИНЫМ Ю.А. С ДЕЛЬНЫМИ ПОЖЕЛАНИЯМИ ПРОСИМ ПО АДРЕСУ: 394043 г. Воронеж ул. Фронтовая 5».
* `SL.SYS` — «АДАПТАЦИЯ ДЛЯ УБПК НПФ "СЕНСОР"».
* The monitor of this kit — «Самые лучшие драйверы для УПБК!!!».

So the firm is named twice, once as **СПФ** and once as **НПФ** «Сенсор», always beside Михин Ю.А. and always in Voronezh, the plant's own city, and always about the УБПК.  That it was a part of the «Процессор» plant is likely and unproved: neither the plant's forum thread nor the encyclopedias name it.
