# The diskettes' manuals, readable

Manuals that came on the diskettes, converted to Markdown so they can be
read here without the machine: the text as it is, in UTF-8 instead of the
originals' KOI-8 or CP866.  These files are ours, made of the originals;
the originals themselves, the recovered bytes, sit with their programs:
