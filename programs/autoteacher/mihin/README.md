# AutoTeacher: Mihin's OS-16SJ kits

The disks disk1, disk2 and amk disk3 - Mihin-soft's OS-16SJ («Самые лучшие драйверы для УПБК!!!»): its own sysgen, utilities with the English DEC-style messages, the FDZ formatter, the Mihin SL.  The exemplar `systems/mihin.dsk` is built from amk_1 of the same family.

The builds below are the ones these disks carried; each card says on which of them it was found, and where a near-identical copy (a few bytes off - bit rot, a patched banner) lies on another disk.

| file | what | how to run |
|---|---|---|
| `CR.SAV` | The question-bank constructor as Mihin's disks carry it  (on amk disk3, disk1, disk2) | `RUN CR` |
