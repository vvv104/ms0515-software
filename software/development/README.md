# Development software

The programming systems that came to the machine from outside its kits,
with their sources on the record and built here from them.

| where | what |
|---|---|
| [`decusc/`](decusc/README.md) | DECUS C, the C compiler the machine's own C programs were made with, rebuilt from the RT-11 SIG tape's sources: `noeis/` for the machine as it is, `eis/` for the machine with `EM.SYS`, the same names in each, the headers in `include/`, and the tape's software tools (`GREP`, `DIFF`, `WC`, `MP`...) built both ways |

What a kit shipped to write programs with - MACRO-11, Pascal, FORTRAN,
the BASICs, the editors - is under [`kits/common/development/`](../../kits/common/development/README.md).
