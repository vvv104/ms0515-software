# Development

What is left here is the sprite editor and the two Hello-world examples that teach the build cycle.  Everything one writes programs with — the macro library, Pascal with its libraries, FORTRAN, the BASICs, the screen editor, the dump viewer — runs under any monitor and survived in one build each, so it went to [`../../kits/common/development/`](../../kits/common/development/README.md); each kit's own assembler and linker are in that kit's `development/`.
