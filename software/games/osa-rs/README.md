# Games: ОСА with the RS profShell

The ОСА disks System2, bg0515, superBAK7 and Buhgal - the monitor configuration that bakes `@START` and shipped the RS profShell commander and Сторожевых's SL V08.00, both announcing themselves at every boot.

The builds below are the ones these disks carried; each card says on which of them it was found, and where a near-identical copy (a few bytes off - bit rot, a patched banner) lies on another disk.

| file | what | how to run |
|---|---|---|
| `HANOJ.SAV` | The Towers of Hanoi as bg0515 carries it - the same program with its text in the other letter case (1467 single-bit flips: the case bit)  (on bg0515) | `RUN HANOJ` |
| `KOSMOS.SAV` | KOSMOS of the System, System2, System3, bg0515 and osa disks - the text in one letter case  (on System, System2, System3, bg0515, osa) | bare prompt, no answer to a bogus file name |
