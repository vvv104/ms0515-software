# Pac-Man family

Five Pac-Man games.  Four of one school, each with a twenty-line «PAC-HALL» table of past players: `PACM.SAV` (English prompts, BEGIN? / ONCE MORE?), `PAC6.SAV` (PACMAN V5.2 with six mazes, «начнём?»), `SP13.SAV` and `SP49.SAV` («Labyrinths of power», the Rostov-on-Don rework of 1986) - `RUN NAME`, `Y` to begin, keys 4/6 left-right and 8/5 up-down.  And `LABRN.SAV`, a different one: a big ASCII labyrinth with runs and matches, a difficulty class 1-127 and a best-results file `LABRN.DAT` beside it; it needs the system date set (`DATE 1-JAN-95`) first.  PACM and PAC6 ship under their true names: each re-opens its own file (`DK:PACM.SAV`, `DK:PAC6.SAV` - the mazes are inside), so the SP15/SP16 names they were found under would not work.  Real-time games: in the CLI start the emulator with `--realtime`.

| file | what | how to run |
|---|---|---|
| `LABRN.DAT` | Best-results file of the LABRN Pac-Man: place, name, date, points, class, total (one entry survives: TOM, 12-FEB-93, class 5); the game refuses to start without it | data file of `LABRN.SAV`, keep beside it |
| `LABRN.SAV` | Pac-Man in a big ASCII labyrinth (LABRN = лабиринт): you are «>O<», eating the dots of the maze, «@» are the ghosts, a start/finish line marks the lap; runs are «забеги», sets of runs «матчи» (П continue the run, Н new run, М new match), difficulty is the «класс» 1-127 asked at start; keeps a best-results table (place, name, date, points, class, total) in LABRN.DAT and saves yours on «ЗАПОМНИТЬ [Д/Н]». Refuses to start without a system date («НЕТ ДАТЫ») and without its results file | set the date first (`DATE 1-JAN-95`), then `RUN LABRN` with `LABRN.DAT` beside it; class 1-127, `Y` at ПУСК? |
| `PAC6.SAV` | PACMAN V5.2 with six mazes («Pac-hall» table, «начнём?», «ещё раз?», «Don't move program volume») - shipped as PAC6.SAV: the program opens DK:PAC6.SAV, its own file, where the six 2 KB text mazes sit from byte 0x1400 («I read maze»), so SP16 was a later renaming. Answer Y at «начнём?»; keys 4/6 left-right, 8/5 up-down. Plays in the GUI; the headless CLI runs the machine unthrottled unless started with --realtime, so the probe saw the game over before it started | `RUN PAC6`, `Y` to begin, keys 4/6/8/5 - it re-opens its own file as DK:PAC6.SAV (its six mazes are inside), so it must keep this name |
| `PACM.SAV` | Pac-Man («PAC-HALL» score table of twenty lines, BEGIN? / ONCE MORE?) - shipped as PACM.SAV: the program opens DK:PACM.SAV, its own file, so SP15 was a later renaming. Answer Y at BEGIN?; keys 4/6 left-right, 8/5 up-down. Plays in the GUI; the headless CLI runs the machine unthrottled unless started with --realtime, so the probe saw the game over before it started | `RUN PACM`, `Y` to begin, keys 4/6/8/5 - it re-opens its own file as DK:PACM.SAV, so it must keep this name |
| `SP13.SAV` | Game with a hall-of-fame table of past players and scores; asks whether to start. Keys 4/6/8/5; plays in the GUI (the CLI needs --realtime, unthrottled it ends at once) | `RUN SP13` |
| `SP49.SAV` | Game "Labyrinths of power" with a hall-of-fame table of past players and scores. Keys 4/6/8/5; plays in the GUI (the CLI needs --realtime, unthrottled it ends at once) | `RUN SP49` |
