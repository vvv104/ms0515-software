# Saboteur 2

«Saboteur 2», omega-games 1991: `SABOT2.SAV` is a small loader that reads the 85-block game body `SABOT2.DAT` into high memory, overlays the monitor and reboots on exit - it needs the full 128 KB machine and the data file beside it.  Two builds of the body survived and both ship, each in its own folder with a copy of the loader: `osa/` from the ОСА disks (keyboard), `omega/` from the omega-games disk 059 (reads the joystick).  The loader opens `DZ:SABOT2.DAT` by device name, so it runs only from a DZ system volume (not a DV-booted one): copy either folder's two files onto a DZ system disk and `R SABOT2`.  The high-score table opens with the localizers' names - IGOR IWAN, IWAN ALEKS, GENNADIJ P., JURIJ IGOR, LENA - above the original DARREN, NOEL, BRAD...


`fixed/` holds both bodies with one six-byte repair, and the untouched originals stay above it.  One room - the corridor under the green building, reached by walking left from the "BIKE ARRIVED" screen - kills the machine in both builds and on other emulators: its floor is a fill of exactly 256 tiles, written in the data as a count byte of 0 the way `LD B,0` / `DJNZ` counts on a Spectrum, and the port translated the loop as `SOB`, where 0 means 65536 passes.  The fill then sweeps the whole address space and takes the memory dispatcher and register C with it.  The repair restores the intended semantics in the engine's loop - `SOB R1, loop` becomes `DECB R1` / `BNE loop`, and the freed exit jumps to a neighbouring routine's - so counts 1..255 behave exactly as before and 0 runs 256 times.  Six bytes change, at 020222 in the ОСА body and 020320 in the omega one; nothing moves.  Verified from the saved states that crash: the room draws whole and the game plays on.
