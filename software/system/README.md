# System software

Everything that runs the machine rather than the user: the device handlers, the RT-11 utilities and the shells.  The monitors themselves are not duplicated here - every code-distinct build is in `../../systems/` (patched to run DEC's STARTS.COM; the three factory configurations that differ only in that baked command are described there).  Each subfolder says which build goes with which system; a disk composed from the collection carries the minimum kit, so copy from here only what you add.
