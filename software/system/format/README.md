# Formatters

Diskette formatters — DESTRUCTIVE, they wipe the surface they format.  Use them on a blank image mounted as the second drive, never on your system disk.

| file | what | how to run |
|---|---|---|
| `FDZ.SAV` | Diskette formatter for the UVK-16; (C) Mihin-soft & SPF Sensor, Voronezh, 1990.  Destructive: it asks Y/N and then formats | `RUN FDZ` |

Programs that survived in several builds - `FORMH.SAV`, `FORML.SAV` - have one folder per kit here, each build in the folder of the disks it came from: `omega/` - the ОМЕГА kits; `vvv/` - the collector's disks.  The files in the table are common to every kit.
